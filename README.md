# FastAPI Notes App Backend

A robust and secure FastAPI backend for managing user notes. This project features JWT-based authentication, PostgreSQL integration via SQLAlchemy, and a clean package structure.

## Features

- **User Authentication**: Secure registration and login using JWT tokens and Argon2 password hashing.
- **Notes Management**: Complete CRUD operations for personal notes.
- **Role-Based Access**: Support for regular users and administrators.
- **API Documentation**: Interactive Swagger UI and Redoc documentation automatically generated by FastAPI.
- **CORS Support**: Configured for cross-origin access.

## Tech Stack

- **Framework**: FastAPI
- **Database**: PostgreSQL
- **ORM**: SQLAlchemy
- **Validation**: Pydantic
- **Security**: Authlib/PyJWT, Argon2

## Getting Started

### Prerequisites

1.  **PostgreSQL**: Ensure you have PostgreSQL installed and running.
2.  **Database**: Create a database named `notes_app`.
    ```sql
    CREATE DATABASE notes_app;
    ```

### Setup

1.  **Clone the repository** (if you haven't already).
2.  **Navigate to the app directory**:
    ```powershell
    cd app
    ```
3.  **Activate the virtual environment**:
    ```powershell
    .\venv\Scripts\activate
    ```
4.  **Install dependencies**:
    ```powershell
    pip install -r requirements.txt
    ```
5.  **Environment Configuration**:
    Create a `.env` file in the `app/` directory (refer to the documentation or implementation plan for required keys like `DATABASE_URL`, `SECRET_KEY`, etc.).

### Running the Application

Start the development server:
```powershell
uvicorn main:app --reload
```
